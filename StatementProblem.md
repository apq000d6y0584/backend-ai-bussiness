# Pernyataan Masalah: BI-AI Engine untuk Analisis Pasar Saham

## Latar Belakang (Why - Mengapa)
Investor dan analis pasar menghadapi tantangan dalam mengintegrasikan **data kuantitatif** (harga saham historis) dan **data kualitatif** (sentimen berita) secara real-time. Proses manual:
- Memakan waktu (scraping, analisis sentimen)
- Subyektif (interpretasi berita)
- Tidak skalabel (sulit analisis multiple ticker)
- Rentan error (rate limiting, data inconsistency)

**Kondisi yang ingin diperbaiki**: Kurangnya tool otomatis yang menggabungkan **AI sentiment analysis (FinBERT)** dengan **data harga real-time (yfinance)** untuk memberikan **skor sentimen (1-10)** + **rekomendasi bisnis actionable**.

## 5W+1H Analysis

### **What (Apa)**: 
Sistem **Business Intelligence AI Engine** yang:
- Mengambil harga penutupan 7 hari dari **Yahoo Finance**
- Scraping berita terkini **CNBC World Markets**
- Analisis sentimen berita menggunakan **FinBERT/DistilRoBERTa**
- Menghasilkan **skor gabungan 1-10** (40% harga + 60% sentimen)
- Generate **3 rekomendasi bisnis** (Buy/Hold/Sell + prioritas)

**Input**: Ticker saham (AAPL, MSFT, TSLA)
**Output**: JSON lengkap untuk frontend dashboard

### **Who (Siapa)**: 
- **Pengguna akhir**: Trader individu, analis keuangan, investor retail
- **Target market**: Pengguna Next.js dashboard (Indonesia/global)
- **Developer**: Tim yang butuh API market analysis siap pakai

### **Where (Di mana)**: 
- **Backend**: FastAPI REST API (`localhost:8000/api/bi?ticker=AAPL`)
- **Frontend**: Next.js dashboard (`localhost:3000`)
- **Data sources**: Yahoo Finance + CNBC.com
- **Database**: Supabase PostgreSQL (opsional)
- **Deployment**: Railway/Heroku/Vercel ready

### **When (Kapan)**: 
- **Real-time analysis**: Data harga 7 hari terakhir + berita terkini
- **Cache TTL**: 1 jam (hindari rate limiting)
- **Model loading**: Lazy (singleton FinBERT)
- **Penggunaan optimal**: Market hours (9:30-16:00 ET)

### **Why (Mengapa dibuat)**: 
**Masalah bisnis yang diselesaikan**:
1. **Edge kompetitif**: AI sentimen > human analyst
2. **Scalability**: Batch analysis multiple ticker
3. **Cost-effective**: Gratis (open-source models + APIs)
4. **User-friendly**: JSON API + responsive dashboard

**Value proposition**: 
```
Manual: 30-60 menit/analysis → AI Engine: 10-30 detik/analysis
```

### **How (Bagaimana)**: 
**Pipeline otomatis**:
```
Ticker Input → [yfinance] → Harga 7 hari
             → [BeautifulSoup] → CNBC headlines  
             → [FinBERT] → Sentiment score (1-10)
             → [Fusion Logic] → Gabung + rekomendasi
             → [Supabase] → Persist
             → [FastAPI] → JSON Response
```

## Root Cause Analysis
```
Problem: Manual market analysis lambat & subyektif
├── Technical: Tidak ada integrasi data sources
├── Business: Trader butuh insight cepat
└── Cognitive: Human bias dalam sentiment interpretation
```

## Issue yang Akan Diselesaikan
1. **Tidak ada tool all-in-one** untuk stock + news + AI sentiment
2. **Proxy conflicts** dengan Supabase di cloud deployment
3. **Rate limiting** Yahoo Finance/CNBC tanpa cache
4. **Model memory** FinBERT berat → pakai DistilRoBERTa

**Kesimpulan**: BI-AI Engine menyelesaikan **gap kritis** antara data pasar mentah dan **insight bisnis actionable** dengan **AI-powered analysis pipeline** yang skalabel dan production-ready.
