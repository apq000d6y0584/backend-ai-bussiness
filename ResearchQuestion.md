# Research Questions & Hypotheses for BI-AI Engine

Generated from BI-AI Engine codebase: automated stock analysis pipeline integrating yfinance prices, CNBC news scraping, FinBERT sentiment, combined scoring (40% quant + 60% qual), and recommendations.

## RQ1: Model Accuracy
**Hypothesis**: FinBERT sentiment scores correlate >70% with actual 7-day forward price returns (better than keyword baselines).

**Data Collection**:
- Run pipeline on 100 S&P500 tickers (daily, 30 days).
- Collect: headlines, FinBERT scores (1-10), actual %change (day+7).
- Sources: Existing (yfinance, CNBC), extend to multiple dates.

**Analysis Methods**:
1. Pearson correlation (score vs forward return).
2. Regression: score ~ return + controls (volatility).
3. Baseline: keyword count (POSITIVE_KEYWORDS vs NEGATIVE_KEYWORDS).

**Resolution**:
| Result | Interpretation |
|--------|----------------|
| Corr >0.7 | Strong predictive power |
| 0.4-0.7 | Moderate utility |
| <0.4 | Needs fine-tuning |

**Success Metric**: p-value <0.01, R²>0.25.

**Analysis Methods**:

**Resolution**:

- If <90%, add fallbacks (Reuters, Yahoo News).

**Success Metric**: Success ≥90%, keywords ≥1.5 avg.

## RQ3: Combined Score Effectiveness
**Hypothesis**: Optimal weighting (60% sentiment + 40% price) outperforms equal (50/50) or price-only baselines in backtesting returns.

**Data Collection**:
- Historical run: 50 tickers × 60 days.
- Compute scores: current (60/40), alt1 (50/50), alt2 (100% price).
- Simulate: Buy if score≥7, Sell ≤4, Hold else; track portfolio return.

**Analysis Methods**:
1. Sharpe ratio, max drawdown per strategy.
2. ANOVA: returns ~ strategy.
3. ROC curve (score threshold vs buy/sell accuracy).

**Resolution**:
| Weighting | Expected Sharpe |
|-----------|-----------------|
| 60/40     | >1.2           |
| 50/50     | >1.0           |
| Price-only| <0.8           |

**Success Metric**: 60/40 Sharpe > others (p<0.05).

**Analysis Methods**:

**Resolution**:
